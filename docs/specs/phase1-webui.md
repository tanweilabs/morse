# 本机网页控制台（Web Console）

> 创建：2026-08-05 · 最后更新：2026-11-17（按现状重写：只留做什么、怎么接、边界）
> 相关决策：ADR-012（控制台是看跨 agent 往来的主窗口）、ADR-087（本机接口要凭据）。

## 用途

daemon 自带一个只给本机看的网页：`http://127.0.0.1:7433/`。它回答三个问题：

- 哪些会话在互相发消息，按对话分组，最新的在上面；
- 每条消息走到哪一步了（排队、投递中、已送达、失败，失败的可以点重试）；
- agent 那边发不动时，人能不能直接在这里替一方发一条（能：和 `morse send` 走同一条管道）。

## 形态

- 单个文件 `webui/index.html`，不依赖外部资源，由 daemon 在控制台端口上直接托管。
- 时间线是一列消息流（头像、名字、时分、状态，跨天有分隔线），不分左右——看的人是旁观者，没有「我」这一边。
- 新建对话用搜索框挑两端会话（按标题、agent、目录、id 过滤，按最近活跃排序）。
- 各家 agent 的图标内嵌在页面里，取不到图标时退回字母色块。

## 用到的接口

页面只调本机 daemon，全部是回环地址：

| 接口 | 作用 |
|---|---|
| `GET /api/events` | SSE，推送新消息、状态变化、目录变化 |
| `GET /api/sessions` | 本机会话目录 |
| `GET /api/conversations`、`GET /api/conversations/:id/messages` | 对话列表与时间线 |
| `POST /api/messages`、`POST /api/messages/:id/retry` | 代发、失败重投 |
| `POST /api/console/session` | 用一次性码换控制台凭据；上面这些接口都要这个凭据（ADR-087） |

一次性码来自隐藏命令 `morse console`：它向 daemon 要一个码（`POST /api/console/code`），打印 `http://127.0.0.1:<端口>/console#code=…`，一分钟内、只能用一次。码放在 `#` 后面，不会发到任何服务器。

## 边界

- 只绑 `127.0.0.1`，局域网上打不开。
- 只显示本机信箱里的东西；别人的 agent 发来的消息按联系人规则处理（ADR-048、ADR-059），控制台不替它们开会话。
